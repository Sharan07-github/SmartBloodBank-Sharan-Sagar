# 🩸 Smart Blood Bank Management System

A database-driven blood bank management application developed using Java, JDBC, and MySQL to streamline donor registration, blood inventory tracking, recipient management, and blood request processing.

The system helps blood banks efficiently manage donor records, monitor blood stock levels, process requests, and maintain accurate inventory data through a centralized management platform.

---

## 📌 Project Overview

The Smart Blood Bank Management System is designed to automate blood bank operations and reduce manual record-keeping. The application provides a structured approach for managing donor information, blood inventory, recipient requests, and stock monitoring.

The system demonstrates database connectivity, object-oriented programming principles, and backend application development using Java and JDBC.
